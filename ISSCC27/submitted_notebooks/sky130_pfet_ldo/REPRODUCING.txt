Reproducing the SKY130 circuit experiments

Use Python 3.10 or newer and ngspice. The recorded simulations use Python 3.12 and ngspice 47. Install the Python packages with:

python -m pip install -r requirements.txt

Put the ngspice executable on PATH or set NGSPICE_EXE. Official downloads are available at https://ngspice.sourceforge.io/download.html. The transistor models are included under models with their original license. Their electrical parameters are unchanged.

Open sky130_pfet_ldo.ipynb in this project directory and run all cells. Alternatively run these commands in order:

python scripts/run_core.py
python scripts/run_load_screen.py
python scripts/run_refined.py
python scripts/run_transient_screen.py
python scripts/run_cff_screen.py
python scripts/run_pass_disturbance.py
python scripts/run_supply_actuator.py
python scripts/check_power_equations.py
python scripts/run_power_refinement.py
python scripts/check_reproduction.py

run_power_refinement evaluates the selected circuit, seven nominal loads, supply and reference responses, observable poles, load transitions, fixed process and temperature cases, and driver and capacitor variations. Its circuit source is circuits/power_refinement/selected.spice. Fixed bias voltages are used throughout.

The earlier experiments evaluate the initial core, direct VIN to gate capacitance and moving the follower source and body from VOUT to VIN. run_pass_disturbance measures an isolated pass transistor with a fixed output. Its current response is not connected regulator PSR.

diagnose_lf_psr reconstructs the low frequency supply paths from native operating parameters for the selected circuit and the two public SKY130 comparisons.

check_power_equations verifies the reduced polynomial equations against direct node solutions. check_reproduction compares the reproduced measurements with the recorded results. Recorded data is under results/recorded. Executions create separate result folders with the simulated circuits, logs and numerical tables. A simulator error or missing output stops execution.

The isolated pass and gate charge experiments use recorded/refined_operating_point.json under results as their fixed bias fixture. Update the fixture when changing those devices. Connected experiments calculate a new operating point.

All experiments use ideal reference and bias ports and zero diffusion areas and perimeters. VIN overhead excludes the separately supplied reference current and generator power. The results do not include extracted layout parasitics, startup or mismatch. The notebook describes the remaining PSR, transient and corner limitations.
